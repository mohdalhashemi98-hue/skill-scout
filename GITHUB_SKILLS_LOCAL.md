# GitHub Skills You Can Use on Your PC

A curated list of [GitHub Skills](https://github.com/skills) courses that involve local/PC work.

## Quick Start

1. Go to the skill's repo (e.g., `github.com/skills/introduction-to-git`)
2. Click **"Use this template"** to create your own copy
3. Clone it: `git clone <your-repo-url>`
4. Follow the instructions in the Issues tab
