### Pixel Agents (VS Code Extension)
- **Repo:** https://github.com/pablodelucca/pixel-agents
- **What:** VS Code extension that turns AI coding agents (Claude Code) into animated pixel art characters in a virtual office
- **How:** Watches Claude Code's JSONL transcript files to track subagent activity in real-time
